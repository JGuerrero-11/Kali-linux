# Kali Linux: utilidades y herramientas para la seguridad informática

![Logo de Kali Linux](https://www.kali.org/images/kali-logo.svg)

## Introducción

**Kali Linux** es una distribución basada en Debian orientada a profesionales de la ciberseguridad, administradores de sistemas y estudiantes. Incluye herramientas para análisis de vulnerabilidades, auditorías de seguridad, pruebas de penetración, ingeniería inversa y respuesta a incidentes.

> ⚠️ Utiliza estas herramientas únicamente en equipos propios o con autorización expresa.

## ¿Qué es Kali Linux?

Kali Linux fue desarrollado por Offensive Security y puede ejecutarse como instalación física, máquina virtual, contenedor o sistema portable desde una memoria USB.

Sus principales características son:

- Amplio catálogo de herramientas de seguridad preinstaladas.
- Compatibilidad con sistemas basados en Debian.
- Actualizaciones periódicas.
- Compatibilidad con máquinas virtuales y sistemas Live USB.
- Entornos preparados para pruebas controladas.

## Principales utilidades

### Reconocimiento y recopilación de información

| Herramienta | Utilidad principal |
|---|---|
| **Nmap** | Descubrimiento de equipos y puertos |
| **Gobuster** | Enumeración de directorios y archivos web |
| **TheHarvester** | Recopilación pública de correos y subdominios |

### Análisis de vulnerabilidades

- **Nmap con scripts NSE:** automatiza comprobaciones de seguridad.
- **OpenVAS:** realiza escaneos completos de vulnerabilidades.
- **Nikto:** inspecciona servidores web.

### Pruebas de aplicaciones web

- **Burp Suite:** intercepta y modifica peticiones HTTP.
- **OWASP ZAP:** detecta vulnerabilidades como XSS e inyección.
- **Sqlmap:** ayuda a comprobar fallos de inyección SQL.

### Auditoría de redes inalámbricas

- **Aircrack-ng:** auditoría de redes Wi-Fi.
- **Wireshark:** captura y análisis de tráfico de red.
- **Kismet:** detección de redes y dispositivos inalámbricos.

### Ingeniería inversa y análisis forense

- **Ghidra:** desensambla y analiza binarios.
- **Autopsy:** investiga sistemas de archivos y evidencia digital.
- **Binwalk:** identifica componentes dentro de firmware.

### Pruebas controladas de autenticación

- **Hydra:** prueba mecanismos de autenticación.
- **John the Ripper:** evalúa contraseñas de prueba.
- **Hashcat:** realiza análisis de hashes.

## Ejemplo básico de uso

Comprobación de equipos activos en una red propia:

```bash
nmap -sn 192.168.1.0/24
```

Identificación de servicios:

```bash
nmap -sV 192.168.1.10
```

Captura de tráfico con Wireshark:

```bash
sudo wireshark
```

## Ventajas

- Entorno especializado con numerosas herramientas.
- Actualizaciones frecuentes.
- Gran comunidad y documentación.
- Fácil uso en máquinas virtuales.
- Adecuado para laboratorios de seguridad.

## Limitaciones y buenas prácticas

- No convierte automáticamente al usuario en un experto.
- Algunas herramientas pueden consumir muchos recursos.
- Requiere conocimientos de redes y sistemas.
- Debe utilizarse dentro de entornos autorizados.
- Las pruebas deben planificarse y limitarse al alcance permitido.

## Instalación

1. Descarga Kali Linux desde el sitio oficial:
   <https://www.kali.org/get-kali/>
2. Selecciona una instalación ISO, máquina virtual o Live USB.
3. Actualiza el sistema:

```bash
sudo apt update
sudo apt full-upgrade -y
```

## Conclusión

Kali Linux es una plataforma potente para aprender y practicar técnicas de ciberseguridad en entornos legales y controlados. Su gran colección de herramientas permite realizar reconocimiento, análisis de vulnerabilidades, pruebas de penetración y análisis forense, siempre con responsabilidad y autorización.

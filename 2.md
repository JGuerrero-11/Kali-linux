## Introducción

**Kali Linux** es una distribución Linux de tipo *rolling release* basada en Debian Testing, orientada a profesionales de la ciberseguridad, administradores de sistemas y estudiantes. Incluye un catálogo especializado de herramientas para análisis de vulnerabilidades, auditorías de seguridad, pruebas de penetración, ingeniería inversa y análisis forense.

> [!WARNING]
> **Aviso legal:** Utiliza estas herramientas únicamente en sistemas propios o en entornos donde cuentes con autorización expresa y por escrito.

---

## ¿Qué es Kali Linux?

Desarrollado y mantenido por **OffSec** (anteriormente Offensive Security), Kali Linux ofrece flexibilidad de despliegue: puede ejecutarse como sistema principal, máquina virtual, contenedor (Docker), subsistema en Windows (WSL) o en modo *Live USB* sin modificar el disco anfitrión.

**Características principales:**

- **Catálogo modular:** Más de 600 herramientas de auditoría organizadas mediante metapaquetes (`kali-linux-default`, `kali-linux-large`, `kali-linux-headless`).
- **Base Debian:** Estabilidad, gestor de paquetes `APT` y amplia compatibilidad de hardware.
- **Actualizaciones continuas:** Parches y nuevas versiones de herramientas sin necesidad de reinstalar el sistema.
- **Entornos aislados:** Soporte nativo para imágenes preconfiguradas de VirtualBox, VMware y QEMU.

## Principales utilidades

### Reconocimiento y recopilación de información

| Herramienta | Utilidad principal | Comando base |
| :--- | :--- | :--- |
| **Nmap** | Descubrimiento de equipos, puertos y servicios | `nmap` |
| **Gobuster** | Enumeración de directorios, archivos y subdominios | `gobuster` |
| **theHarvester** | Recopilación OSINT de correos, dominios e IPs | `theHarvester` |

### Análisis de vulnerabilidades

| Herramienta | Utilidad principal | Comando base |
| :--- | :--- | :--- |
| **Nmap (NSE)** | Comprobaciones automatizadas mediante scripts | `nmap --script` |
| **OpenVAS (GVM)** | Escaneos completos de vulnerabilidades en red | `gvm-start` |
| **Nikto** | Inspección de configuraciones y fallos en servidores web | `nikto` |

### Pruebas de aplicaciones web

| Herramienta | Utilidad principal | Comando base |
| :--- | :--- | :--- |
| **Burp Suite** | Proxy de intercepción y modificación de tráfico HTTP/S | `burpsuite` |
| **OWASP ZAP** | Detección automatizada de XSS, CSRF y malas configuraciones | `zaproxy` |
| **sqlmap** | Detección y validación de inyecciones SQL | `sqlmap` |

### Auditoría de redes inalámbricas y tráfico

| Herramienta | Utilidad principal | Comando base |
| :--- | :--- | :--- |
| **Aircrack-ng** | Suite de auditoría para redes Wi-Fi | `aircrack-ng` |
| **Wireshark** | Captura e inspección profunda de paquetes de red | `wireshark` |
| **Kismet** | Detección pasiva de redes y dispositivos inalámbricos | `kismet` |

### Ingeniería inversa y análisis forense

| Herramienta | Utilidad principal | Comando base |
| :--- | :--- | :--- |
| **Ghidra** | Desensamblado y descompilación de binarios | `ghidra` |
| **Autopsy** | Investigación forense de discos y evidencias digitales | `autopsy` |
| **Binwalk** | Análisis y extracción de componentes en imágenes de firmware | `binwalk` |

### Pruebas controladas de autenticación

| Herramienta | Utilidad principal | Comando base |

## Ejemplos básicos de uso

Descubrimiento de equipos activos en una red local propia (escaneo de ping sin sondeo de puertos):

```bash
nmap -sn 192.168.1.0/24
```

Detección de puertos abiertos y versiones de servicios en un equipo de laboratorio:

```bash
nmap -sV 192.168.1.10
```

## Ventajas y limitaciones

| Ventajas | Limitaciones y buenas prácticas |
| :--- | :--- |
| Entorno especializado listo para usar en laboratorios. | No sustituye el conocimiento sólido de redes y sistemas. |
| Actualizaciones frecuentes y amplia documentación oficial. | Algunas herramientas exigen altos recursos de CPU y RAM. |
| Despliegue rápido en máquinas virtuales y contenedores. | No se recomienda como sistema operativo de uso diario general. |
| Gran comunidad y soporte técnico activo. | Toda auditoría debe limitarse estrictamente al alcance autorizado. |

## Instalación y actualización

1. Descarga la imagen correspondiente (ISO, máquina virtual o Live USB) desde el [portal oficial de descargas](https://www.kali.org/get-kali/).
2. Verifica la integridad del archivo descargado comparando su suma `SHA256`.
3. Tras iniciar el sistema, actualiza los repositorios y paquetes instalados:

```bash
sudo apt update && sudo apt full-upgrade -y
```

## Conclusión

Kali Linux constituye un estándar técnico para la formación y el ejercicio profesional de la ciberseguridad en entornos controlados. Su catálogo estructurado cubre todas las fases de una auditoría —desde el reconocimiento inicial hasta el análisis forense—, exigiendo siempre rigor metodológico, base técnica y autorización previa.
